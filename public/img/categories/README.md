# Category illustrations

Flat, solid-colour illustrations (800x600, 4:3) used on the By category cards and category tiles:
`plumbing.svg`, `electrical.svg`, `lift.svg`, `housekeeping.svg`, `security.svg`, `other.svg`.

They use only the dashboard palette (dark teal #0a303e, soft tints, brand teal #0088b0). To use real photos instead, add JPGs
and change the extension in `catPic` (public/web.js) and `catPhoto` (public/m/m.js). If a file is missing the cards fall back
to a solid dark-teal card with the category icon.
