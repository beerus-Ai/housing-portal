## AI use disclosure
Claude Code (Anthropic) wrote most of the code, tests and documents in this repository from prompts given by the team, and the team directed, reviewed and ran it. Claude Design produced the visual handoff for the first UI. AI agents were also used in parallel on separate branches. The prompt log above is a summary, not a full transcript. No real resident data was given to Claude; development and tests use synthetic data only. The AI features inside the product send no names, phones, emails or flat numbers to any model and only suggest, with a committee member deciding. Each student must be able to explain and defend any part of the work; this disclosure does not replace that, and the contribution matrix records who did what.
